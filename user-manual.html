1. Quick start

  1. Open Settings and check your presets (paper, ink, printer, quality). Edit them to match your shop.
  2. Go to Settings → Store info & currency and enter your store name and currency. Tick the details you want on receipts.
  3. On the main screen tap Choose file and pick a PDF or image.
  4. Choose your presets (Quick: one setup, or Custom: each preset).
  5. Set pages, copies and options, then tap Analyze & Calculate.
  6. Read the Final Price, then tap Receipt PDF or Receipt Image.

2. First launch

The first time you open the App you choose how to start:

  • Start with ready-made presets: loads the developer’s presets, an ink preset for every ink model and charge mode, and ready-made setups.
  • Start empty: no presets. Create your own in Settings.

You can change your mind later: Settings → Add ready-made presets or Delete all presets.

3. The main screen

3.1 Choose and clear a file

Tap Choose file (PDF or image; Word files need an analysis server). The Clear button removes the chosen file and its result.

3.2 Presets

  • Quick: pick one setup (a saved combination of paper + ink + printer + quality).
  • Custom: pick each preset yourself. The switch appears once you have at least one setup.
  • A grey box shows what the selected presets mean (paper size and charge, ink fixed price or minimums, quality).
  • An amber warning appears if the page count does not fit the tier of the selected presets, or the paper and ink tiers differ. It can offer to switch to a matching setup.

3.3 Pages and options

Every option has an (i) button with a short explanation.

3.4 Analyze & Calculate

The button stays disabled until a file, a paper preset and an ink preset are chosen. While it works, a screen shows Analyzing page X of N and everything is paused. Each calculation is saved to History automatically with a reference number.

3.5 Editing a History record

Tap the pencil on a History record. An amber banner appears. Change what was wrong, pick the file again if asked, and tap Analyze & Calculate. The same record (and reference number) is updated.

The App also remembers the screen: when you close and reopen it, your presets, fields and last result are back.

4. Reading the results

  • FINAL PRICE: the amount to charge. Under it: Paper, Ink, Fees and Setup, and the count of B&W, Color and Blank pages.
  • If you change anything after calculating, the price turns grey with a line through it and a note asks you to calculate again.
  • Receipt PDF and Receipt Image buttons.
  • Print analysis details (closed by default): calculation model, estimated ink (mL) and cost per color, paper, charged ink fee, and View calculation details (every formula input).
  • Page-by-page table (closed by default): coverage C/M/Y/K, type, paper, ink, other and price per page.

Ink amounts are estimates, never exact measurements.

5. How the price is calculated

For every page:

Page price = paper + ink + maintenance + finishing
  • Paper = the higher of (pack cost ÷ sheets) and the paper preset’s Base rate. On duplex each page pays half a sheet.
  • Ink depends on the ink preset’s Charge mode (see below). Blank pages have no ink charge.
  • Maintenance = the printer preset’s per-page fee.
  • Finishing = your finishing fee per page.
Total = (sum of page prices × copies, with paper counted by physical sheets + setup fee)

Charge modes

ModeInk charge per page
Fixed price per pageExactly the Threshold (B&W page) or Color threshold (color page). Real ink use does not change the price.
Consumption with minimumThe estimated ink cost, but never less than the Threshold / Color threshold.

Example

Paper preset “Short (<20 pages)” (base rate 1.00) with an ink preset using Fixed price 1.00 B&W / 2.00 color. A B&W page = 1.00 + 1.00 = 2.00; a color page = 1.00 + 2.00 = 3.00. Ten B&W pages, 1 copy, no extra fees = 20.00.

6. Presets

Open Settings and choose a preset type. Tap a preset to edit it, the copy icon to duplicate it, or the bin to delete it (you are asked twice).

TypeHolds
PaperSize, pack cost, sheets, base rate (your paper price), absorption, ink limit, tier.
InkInk model, charge mode, thresholds, bottle prices and volumes, yields, calibration, maintenance and startup ink, tier.
PrinterBrand, model, maintenance fee per page.
QualityDPI, ink multiplier, color density, max ink limit.

The badges in the editor

Every field shows how it takes part in the calculation, and the badges change live as you edit:

USED IN PRICE changes what the customer pays. ESTIMATE ONLY changes only the ink estimate (not the price in Fixed mode). SOMETIMES counts only in some cases. NOT USED HERE the selected ink model or mode does not use it. INFO ONLY a label.

Ink models

ModelMeaning
Manufacturer YieldUses the page yield on the box. Example: 65 mL ÷ 7,500 pages = 0.0087 mL per page at the reference coverage (5%). A page with 10% coverage uses twice that. An approximation.
Reference CoverageSame, but each color can have its own reference coverage %.
Custom CalibrationUses ink you measured yourself (mL per 1% coverage). Most accurate for your own setup. Estimates 0 mL until you enter values.
Direct mL per coverageUses mL per cm² at 100% coverage × page area × coverage. Needs your measurements.

Epson’s published L5290 yields are black 4,500 pages and 7,500 pages (composite yield) for each of cyan, magenta and yellow. The App keeps them as published. 65 mL is the replacement bottle volume, not the printer’s internal tank capacity.

7. Setups and page-count tiers

Setups (Settings → Setups) save a paper, ink, printer and quality preset together so you can pick them with one tap (Quick mode). A setup remembers preset names; if you rename a preset, pick it again in the setup.

Tiers (Settings → Page-count tiers) are rules like “<20 pages” and “20+ pages”. You can rename them, change the limits or add your own. Give a preset or setup a Tier and the App warns you when the job does not fit it. Tiers never change prices by themselves.

7b. Printer ink levels (optional)

You can track how much ink is left in each color of your printer. Open your Printer preset and fill in Ink tracking:

  • Max = 100% (mL): your own 100% mark for the color, for example one full bottle. (The printer’s internal tank size is not published, so this is your definition.)
  • Ink left: type it as mL or as %. The two boxes are linked: typing one updates the other.
  • Leave a color blank to not track it.
  • Ink tracking mode: Off; Manual (tap Deduct ink from printer on the result after you print); Automatic (every calculation deducts its estimated ink).

The main screen then shows bars with the ink left in each color (red under 15%), with Update and Refill buttons, and warns Not enough ink if a job needs more than what is left. If you edit and recalculate a record, its old deduction is given back first, so nothing is counted twice; Undo deduction gives it back too.

Deductions use the estimated mL of a calculation, so the levels are estimates. Check your printer now and then and update the levels. Maintenance and startup ink are not deducted.

8. Store info and currency

Settings → Store info & currency: store name (Sold by), attendant (Served by), address, contact number, email or social page, business/tax ID, and a footer message. Tick the box in front of a field to print it on receipts; unticked fields never appear.

Choose your currency from the list, or pick Other and type a code and symbol. The App shows the symbol; receipts print the code (for example PHP) because the PDF font cannot draw many symbols.

9. History

  • Every calculation is saved automatically with a reference number like 20261001-1432-0007 (date, time, print number).
  • Tap a record to make its receipt. The pencil edits and recalculates it. The bin deletes it (asked twice).
  • The icons at the top export all records to a file and import them back. Records with a reference number that already exists are skipped.

10. Receipts

Tap Receipt PDF or Receipt Image (one whole tall image, so the table is never cut). A “Preparing…” pop-up shows while it is made, then choose Save to phone or Share. A receipt shows the reference number, date, customer, store details you ticked, the colored page table, subtotal, setup fee (only if above 0) and total. Each file name is unique, so edited receipts never overwrite old ones.

11. Backup and restore

Settings → Export settings & presets lets you choose exactly what to include: store info and currency, analysis server, tiers, each preset type (or individual presets), and optionally History. Import reads such a file and lets you choose what to bring in, and what to do when a name already exists (keep both, skip, or replace). Back up regularly: your data lives only on your phone.

12. Analysis server (optional)

For more accurate coverage and Word file support you can run the included Ghostscript “inkcov” server on your own computer or hosting. Enter its address in Settings → Analysis server (for example http://192.168.1.10:8000) and an optional API key. Your documents are sent to that server only. Leave the address blank to stay fully on-device. If the server cannot be reached, the App falls back to the on-device estimate.

13. Troubleshooting

ProblemWhat to check
The price is not what I expectedCheck the ink preset’s Charge mode. With Fixed price per page the price ignores real ink use. Remember each page is paper + ink + maintenance + finishing. Open the details to see each part.
The price is grey with a lineYou changed something after calculating. Tap Analyze & Calculate again.
Analyze is disabledChoose a file, a paper preset and an ink preset.
A colored page was priced as B&WOn-device detection can miss tiny colored areas. Set Color mode to All Color, or use an analysis server.
Editing a record asks me to pick the file againThe original file is no longer available on the phone. Pick it again.
Warning about tiersThe job’s page count does not fit the preset’s tier. Switch preset or setup, or edit the tier in Settings.
A setup warns about a missing presetA preset it uses was renamed or deleted. Edit the setup and choose it again.
Currency symbol missing on the receiptReceipts print the currency code on purpose.
